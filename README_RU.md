# Forge No-Copy Download

Небольшое расширение для **Stable Diffusion WebUI Forge Neo**, которое
оставляет стандартную кнопку 💾, но не позволяет ей постоянно забивать
`webui/output/images` дубликатами скачиваемых картинок.

При этом сохраняется нормальная нумерация:

`00005-411155239.jpg`

![Нумерация скачиваемых файлов](docs/numbered-download.png)

## Что делает

- оставляет стандартную кнопку 💾;
- оставляет ZIP-скачивание;
- не создаёт постоянные копии от кнопки скачивания в `output/images`;
- использует системную временную папку Windows;
- удаляет старые временные загрузки;
- сохраняет последовательную нумерацию `00000`, `00001`, `00002`...;
- не изменяет файлы ядра Forge на диске.

## Установка

Распакуйте папку:

`forge-no-copy-download`

в:

`Forge Neo/extensions/`

и полностью перезапустите Forge Neo.

В консоли появится:

```text
[Forge Neo] forge-no-copy-download v1.0.0 loaded
```

## Важно

Расширение меняет именно поведение ручной кнопки скачивания. Оно не отключает
автосохранение генераций, если оно включено в Forge или другом расширении.

Текущий файл для скачивания создаётся во временной папке Windows:

```text
%TEMP%\forge-neo-download
```

Счётчик нумерации хранится в:

```text
extensions/forge-no-copy-download/.download_counter
```

## Совместимость

Проверено с **Forge Neo 2.29.1**.

## Удаление

Удалите папку:

`extensions/forge-no-copy-download`

и полностью перезапустите Forge Neo.
